# 🎬 The Film Archive

A cinematic website for movie reviews and streaming recommendations, 
built as a front-end web development project.

🔗 **Live site:** https://rockayam.github.io/thefilmarchiveproject/index.html

## Features
- Multi-page site: Home, Now in Cinemas, New on Streaming, Reviews, About, Contact
- Elegant dark theme with gold accents
- Responsive grid layouts for all screen sizes
- Glass morphism UI effects
- Individual movie review pages with star ratings

## Built With
- HTML5
- CSS3 (Flexbox, Grid, Glass morphism effects)
- Responsive design (mobile-first)

## Pages
| Page | Description |
|------|-------------|
| Home | Featured reviews with poster grid |
| Now in Cinemas | Current theatrical releases |
| New on Streaming | Latest streaming picks |
| Reviews | Full review archive with ratings |
| Contact | Contact form |

## Project Context
Built as part of the Web Development module at the 
University of Southampton (2025–2026).
